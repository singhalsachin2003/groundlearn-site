How it works

Count them

  1. Point at each one and count: 1, 2, 3…
  2. Tap the number that matches.
  3. The last number you say is how many there are.

Explorer labs read instructions aloud, and a wrong try never costs anything.

Why it works

The big idea

Counting is like giving each thing a ticket with a number: the last ticket you give out tells you how many there are.

What children learn

Skills in this lab

  • Counting objects one by one
  • Matching a number to a quantity
  • Numbers up to 10 and beyond
