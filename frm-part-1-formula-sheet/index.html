Foundations of Risk Management

Asset pricing and performance measures.

CAPM

E(Ri) = Rf + βi × [E(Rm) − Rf]

βi = Cov(Ri, Rm) / σm2.

Multi-factor model

E(Ri) = Rf + Σ βik × λk

λk = risk premium for factor k (APT, Fama–French).

Sharpe ratio

(Rp − Rf) / σp

Excess return per unit of total risk.

Treynor ratio

(Rp − Rf) / βp

Excess return per unit of systematic risk.

Jensen's alpha

αp = Rp − [Rf + βp(Rm − Rf)]

Return above the CAPM prediction.

Information ratio and tracking error

IR = (Rp − Rb) / TE    TE = σ(Rp − Rb)

Active return per unit of active risk.

Sortino ratio

(Rp − Rmin) / Downside deviation

Penalises only returns below the minimum acceptable return.

Quantitative Analysis

Probability, regression and volatility modelling.

Bayes' theorem

P(A | B) = P(B | A) × P(A) / P(B)

The classic FRM application is updating default or manager-skill probabilities.

Binomial and Poisson

P(X = k) = C(n, k) pk(1 − p)n − k    P(X = k) = λk e−λ / k!

Poisson for counts of events such as defaults or losses.

Variance of a sum

Var(aX + bY) = a2Var(X) + b2Var(Y) + 2ab Cov(X, Y)

The basis of portfolio variance.

OLS slope and intercept

β̂ = Cov(X, Y) / Var(X)    α̂ = Ȳ − β̂X̄

t = β̂ / SE(β̂).

Adjusted R-squared

R̄2 = 1 − (1 − R2) × (n − 1) / (n − k − 1)

k = number of regressors. Penalises adding weak variables.

EWMA volatility

σt2 = λσt−12 + (1 − λ) rt−12

RiskMetrics uses λ = 0.94 for daily data.

GARCH(1,1)

σt2 = ω + α rt−12 + β σt−12

Long-run variance = ω / (1 − α − β). Persistence = α + β < 1.

Square-root-of-time rule

σT = σ1 × √T

Holds only for independent, identically distributed returns.

Financial Markets and Products

Forwards and futures, hedging, swaps and bond futures.

Forward price, continuous compounding

F0 = S0 e(r − q)T

q = dividend yield. Currencies: F0 = S0 e(rd − rf)T.

Commodity forward

F0 = S0 e(r + u − y)T

u = storage cost, y = convenience yield.

Minimum-variance hedge ratio

h* = ρ × σS / σF    N* = h* × QA / QF

QA = size of the position, QF = size of one contract.

Hedging equity with index futures

N = (β* − β) × P / F

Set β* = 0 to hedge completely.

Duration-based hedge

N = (P × DP) / (F × DF)

Values and durations of the portfolio and the futures contract.

Swap valuation

Vpay fixed = Bfloat − Bfixed

Or value as a portfolio of FRAs.

Cheapest-to-deliver bond

Cost = Quoted bond price − (Quoted futures price × Conversion factor)

Deliver the bond with the lowest cost.

Valuation and Risk Models

VaR and ES, bond risk, options and credit losses.

Parametric VaR

VaR = zc × σ × V

Assumes normal returns with zero mean. Scale with √T over T days.

Expected shortfall, normal

ES = σ × V × φ(zc) / (1 − c)

φ = standard normal density. Always above VaR at the same c.

DV01

DV01 = ModDur × P × 0.0001

Price change for a 1 bp move in yield.

Price change with convexity

ΔP / P ≈ −D × Δy + ½ × C × (Δy)2

Duration overstates losses when yields rise for option-free bonds.

Black–Scholes–Merton

c = S0N(d1) − X e−rT N(d2)

d1 = [ln(S0/X) + (r + σ2/2)T] / (σ√T), d2 = d1 − σ√T.

Option delta

Δcall = N(d1)    Δput = N(d1) − 1

With a dividend yield, multiply by e−qT.

Binomial tree parameters

u = eσ√Δt    d = 1/u    p = (erΔt − d) / (u − d)

Discount the expected payoff at the risk-free rate.

Expected loss

EL = PD × LGD × EAD

The mean credit loss, covered by pricing and provisions.

Unexpected loss

UL = EAD × √(PD × σLGD2 + LGD2 × σPD2)

σPD2 = PD × (1 − PD). Covered by economic capital.
