Quantitative Methods

Returns, time value of money, statistics and simple regression.

Holding period return

HPR = (P1 − P0 + D1) / P0

Price change plus income, over the starting price.

Geometric mean return

RG = [(1 + R1)(1 + R2)…(1 + Rn)]1/n − 1

The compound annual rate. Always at or below the arithmetic mean.

Harmonic mean

XH = n / Σ(1 / Xi)

Average cost per share under cost averaging.

Annualising a return

Rannual = (1 + Rperiod)c − 1

c = number of periods in a year.

Continuously compounded return

rcc = ln(1 + HPR) = ln(P1 / P0)

Continuously compounded returns add across periods.

Real and nominal returns

(1 + rnominal) = (1 + rreal)(1 + π)

π = inflation. The approximation rnominal ≈ rreal + π is only an approximation.

Future value

FV = PV × (1 + r/m)mN

m = compounding periods per year, N = years. Continuous: FV = PV × erN.

Effective annual rate

EAR = (1 + r/m)m − 1

Continuous compounding: EAR = er − 1.

Present value of an ordinary annuity

PV = A × [1 − (1 + r)−N] / r

Annuity due: multiply by (1 + r).

Present value of a perpetuity

PV = A / r

Growing perpetuity: PV = A1 / (r − g), with r > g.

Sample variance and standard deviation

s2 = Σ(Xi − X̄)2 / (n − 1)    s = √s2

Divide by n − 1 for a sample, n for a population.

Coefficient of variation

CV = s / X̄

Risk per unit of return.

Covariance and correlation

ρXY = Cov(X, Y) / (σX σY)

Correlation is bounded between −1 and +1.

Two-asset portfolio variance

σp2 = w12σ12 + w22σ22 + 2w1w2ρ12σ1σ2

Diversification comes from ρ below +1.

Safety-first ratio

SFRatio = [E(Rp) − RL] / σp

Choose the portfolio with the highest ratio. RL = threshold return.

Bayes' formula

P(A | B) = P(B | A) × P(A) / P(B)

Updates a prior probability with new information.

Standard error of the mean

sX̄ = s / √n

Shrinks with the square root of the sample size.

Confidence interval and test statistic

X̄ ± zα/2 × s / √n    t = (X̄ − μ0) / (s / √n)

Use t with n − 1 degrees of freedom when σ is unknown.

Simple linear regression

b̂1 = Cov(X, Y) / Var(X)    b̂0 = Ȳ − b̂1X̄

R2 = SSR / SST. SEE = √[SSE / (n − 2)]. F = MSR / MSE.

Economics

Elasticity, national income, money and exchange rates.

Price elasticity of demand

EP = %ΔQd / %ΔP

|E| > 1 is elastic. Income and cross-price elasticities use the same form.

GDP, expenditure approach

GDP = C + I + G + (X − M)

Consumption, investment, government spending, net exports.

Fiscal multiplier

1 / [1 − MPC × (1 − t)]

t = tax rate, MPC = marginal propensity to consume.

Money multiplier

1 / reserve requirement

Simple deposit multiplier.

Quantity theory of money

M × V = P × Y

Money supply × velocity = price level × real output.

Fisher effect

Rnominal ≈ Rreal + πe

Expected inflation is priced into nominal rates.

Forward exchange rate

Ff/d = Sf/d × (1 + if × Actual/360) / (1 + id × Actual/360)

Covered interest rate parity. The higher-rate currency trades at a forward discount.

Financial Statement Analysis

Earnings per share, ratios, cash flow and inventory.

Basic EPS

(Net income − Preferred dividends) / Weighted average shares

Diluted EPS adds back the effects of convertibles, options and warrants if dilutive.

DuPont analysis

ROE = (NI / Sales) × (Sales / Assets) × (Assets / Equity)

Margin × turnover × leverage.

Liquidity ratios

Current = CA / CL    Quick = (Cash + ST securities + Receivables) / CL

Cash ratio uses cash and marketable securities only.

Activity ratios

Inventory turnover = COGS / Avg inventory    DOH = 365 / Inventory turnover

DSO = 365 / Receivables turnover. DPO = 365 / Payables turnover.

Cash conversion cycle

CCC = DOH + DSO − DPO

Days of financing the operating cycle needs.

Solvency ratios

Debt-to-equity = Total debt / Total equity    Interest coverage = EBIT / Interest

Financial leverage = Avg assets / Avg equity.

Free cash flow to the firm

FCFF = CFO + Interest × (1 − t) − FCInv

Under IFRS, check where interest paid is classified.

Free cash flow to equity

FCFE = CFO − FCInv + Net borrowing

Cash available to common shareholders.

Inventory identity

COGS = Beginning inventory + Purchases − Ending inventory

FIFO inventory = LIFO inventory + LIFO reserve.

Depreciation

Straight-line = (Cost − Salvage) / Life    DDB = (2 / Life) × Beginning book value

DDB ignores salvage until book value reaches it.

Corporate Issuers

Cost of capital, leverage and capital structure.

Weighted average cost of capital

WACC = wd rd(1 − t) + wp rp + we re

Use target or market-value weights.

Cost of equity, CAPM

re = Rf + β × [E(Rm) − Rf]

Bond yield plus risk premium is the common alternative.

Net present value

NPV = Σ CFt / (1 + r)t − CF0

IRR is the rate that sets NPV to zero. Prefer NPV when they conflict.

Degree of operating leverage

DOL = Q(P − V) / [Q(P − V) − F]

DFL = EBIT / (EBIT − Interest). DTL = DOL × DFL.

Breakeven quantity

QBE = (F + C) / (P − V)

F = fixed operating costs, C = fixed financing costs. Operating breakeven drops C.

Modigliani–Miller with taxes

VL = VU + t × D

The debt tax shield adds value until distress costs bite.

Equity Investments

Dividend discount models, multiples and margin.

Gordon growth model

V0 = D1 / (r − g)

Requires r > g and constant growth.

Justified forward P/E

P0 / E1 = (D1 / E1) / (r − g)

Payout ratio over (r − g).

Sustainable growth rate

g = b × ROE

b = retention rate = 1 − payout ratio.

Preferred stock value

V0 = Dp / rp

A perpetuity for non-callable, non-convertible preferred.

Leverage ratio and margin call price

Leverage = 1 / IM    Pcall = P0 × (1 − IM) / (1 − MM)

IM = initial margin, MM = maintenance margin.

Enterprise value

EV = Market value of equity + Debt + Preferred − Cash

EV / EBITDA compares firms with different leverage.

Fixed Income

Bond pricing, yield measures, duration, convexity and credit.

Bond price

P = Σ C / (1 + r)t + FV / (1 + r)N

Per-period coupon and yield for semi-annual bonds.

Full price and accrued interest

Full price = Flat price + AI    AI = (t / T) × PMT

t = days since last coupon, T = days in the coupon period.

Current yield

Annual coupon / Flat price

Ignores pull to par.

Modified duration

ModDur = MacDur / (1 + r)

r = yield per period. %ΔP ≈ −ModDur × Δy.

Approximate duration and convexity

ApproxModDur = (PV− − PV+) / (2 × Δy × PV0)    ApproxCon = (PV− + PV+ − 2PV0) / (Δy2 × PV0)

Effective duration uses the same form with curve shifts, for bonds with options.

Price change with convexity

%ΔP ≈ −ModDur × Δy + ½ × Convexity × (Δy)2

Δy in decimals: 100 bp = 0.01.

Money duration and PVBP

MoneyDur = ModDur × Full price    PVBP = (PV− − PV+) / 2

PVBP uses a 1 bp shift.

Forward rates from spot rates

(1 + S2)2 = (1 + S1) × (1 + f1,1)

No-arbitrage link between spot and forward rates.

Expected credit loss

Expected loss = PD × LGD    LGD = Exposure × (1 − Recovery rate)

Yield spread ≈ PD × LGD, as a first approximation.

Derivatives

Forwards, option payoffs, put–call parity and the binomial model.

Forward price

F0(T) = S0 × (1 + r)T

With income and costs: F0(T) = [S0 − PV(I) + PV(C)] × (1 + r)T.

Value of a long forward during its life

Vt = St − F0(T) / (1 + r)T − t

Zero at initiation.

Option payoffs at expiry

Call = max(0, ST − X)    Put = max(0, X − ST)

Profit subtracts the premium paid.

Put–call parity

c0 + X / (1 + r)T = p0 + S0

Put–call forward parity replaces S0 with F0(T) / (1 + r)T.

One-period binomial model

q = (1 + r − d) / (u − d)    c0 = [q × cu + (1 − q) × cd] / (1 + r)

q is the risk-neutral probability, not a real-world one.

Swap value

Value to payer = PV(floating leg) − PV(fixed leg)

Par swap rate = (1 − DFN) / Σ DFt.

Alternative Investments

Fees and real estate valuation.

Hedge fund fees

Fee = Management % × AUM + Incentive % × (Return above hurdle, net of high-water mark)

Check whether the incentive fee is calculated net of the management fee.

Capitalisation rate

Cap rate = NOI / Property value

Value = NOI1 / Cap rate.

Multiple of invested capital

MOIC = (Realised + Unrealised value) / Invested capital

Ignores timing, unlike IRR.

Portfolio Management and Construction

CAPM, the capital market line and performance measures.

Portfolio expected return

E(Rp) = Σ wi E(Ri)

Weights sum to one.

Utility

U = E(R) − ½ × A × σ2

A = risk aversion coefficient.

Capital market line

E(Rp) = Rf + {[E(Rm) − Rf] / σm} × σp

Efficient portfolios of the risk-free asset and the market.

Beta

βi = Cov(Ri, Rm) / σm2 = ρi,m σi / σm

Systematic risk only.

Security market line (CAPM)

E(Ri) = Rf + βi × [E(Rm) − Rf]

Above the SML = undervalued.

Sharpe and Treynor ratios

Sharpe = (Rp − Rf) / σp    Treynor = (Rp − Rf) / βp

Sharpe for total risk, Treynor for systematic risk.

M-squared and Jensen's alpha

M2 = (Rp − Rf) × σm / σp − (Rm − Rf)    αp = Rp − [Rf + βp(Rm − Rf)]

Both measure risk-adjusted outperformance.
